# Pi-durable — агентное ядро

Ядро сервиса — свой Node/TS-бэкенд поверх `@earendil-works/pi-durable`: проверка ДЗ и напоминания моделируются как durable-задачи (SQLite-хранилище, автопродолжение после падения/рестарта), доступ к моделям — через `@earendil-works/pi-ai` (провайдеро-независимо: OpenAI/Anthropic/OpenRouter/Ollama и др.). Бизнес-состояние (задания, отчёты, вердикты) хранится рядом, в том же SQLite.

## Considered Options

- **Hermes Agent** (`NousResearch/hermes-agent`): готовое Python-приложение-ассистент (Telegram-шлюз, cron, память). Не каркас для своего веб-сервиса: доменную логику пришлось бы протаскивать через skills/MCP, веб-UI отпал бы.
- **Без фреймворка**: прямые LLM-вызовы + cron; resume/retry/очереди задач писать самим — дублировать то, что pi-durable даёт из коробки.

## Consequences

- API pi-durable экспериментальный («меняется без предупреждения между релизами»): пинуем точную версию и изолируем за собственной обёрткой в коде.
- Стек фиксирован на TypeScript/Node; Python в рантайме не участвует.
