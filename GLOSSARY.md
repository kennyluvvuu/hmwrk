# hmwrk

Сервис проверки домашних заданий школьника: родитель заносит ДЗ из скриншота электронного журнала, ребёнок отчитывается в веб-интерфейсе, AI проверяет правильность и полноту, родитель подтверждает вердикты. Если ребёнок не отчитался к дедлайну — уведомление родителю.

## Language

**Задание (Assignment)**:
Домашняя работа по одному предмету, у которой есть дедлайн и текст (обычно распарсенный из скриншота).
_Avoid_: урок, домашка, задача

**Пункт задания (Assignment Item)**:
Отдельное упражнение в составе задания («№12», «упражнение 3»).
_Avoid_: подзадача

**Отчёт (Check-in)**:
Действие ребёнка: заявить, что задание выполнено; сопровождается фото тетради.
_Avoid_: отметка, галочка, сдача

**Прочтение (Reading)**:
Перевод фото тетради в текст силами vision-модели; первый шаг проверки.

**Проверка (Verification)**:
AI-анализ прочитанного отчёта: правильность ответов и полнота выполнения пунктов. Результат — черновой вердикт, вступающий в силу после подтверждения родителем.
_Avoid_: оценка, рецензия

**Дедлайн (Due)**:
Момент, до которого по заданию ожидается отчёт; дедлайн без отчёта — «не отчитался».
_Avoid_: срок, дедлайн задания

**Источник заданий (Intake)**:
Канал, из которого в систему попадают задания до их активации. Сейчас — скриншот (отладочное качество), скоро — парсер электронного журнала.
_Avoid_: загрузка, импорт

**Напоминание (Reminder)**:
Сообщение ребёнку в Telegram до дедлайна: по заданиям без отчёта.
_Avoid_: пуш, нотификация

**Дайджест (Digest)**:
Вечерняя сводка родителю в Telegram: сданное, просроченное, вердикты, ожидающие подтверждения.
_Avoid_: отчёт (занят отчётом ребёнка), сводка

**Родитель (Parent)**:
Роль, которая заносит задания и подтверждает вердикты проверок.
_Avoid_: админ, учитель

**Ребёнок (Child)**:
Роль, которая отчитывается по заданиям.
_Avoid_: ученик, студент, юзер
